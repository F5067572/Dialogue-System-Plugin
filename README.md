# Dialogue System Plugin

This is a designer friendly Dialogue System designed for Unreal Engine, made for storytelling in games.

This System requires 0 extra code for it to work in your projects, just attach it to your Actors or Objects in the world and add Dialogue in the Details Pannel

## How to Set it up

Download the most recent file and import it to your Project. Make sure you add both the Widget and Blueprint to the file. The Dialogue System itself is an Actor which means it can be placed anywhere in the world but it would work best when it is attached to another Actor. The Widget can be changed to look however the player likes but DO NOT remove any of the Widget components unless you know what you are doing.

Creating the Dialogue itself is quite easy.

<img width="473" height="464" alt="image" src="https://github.com/user-attachments/assets/8a69149b-a901-4487-b06c-d27a9a085cb7" />

Each array index in the details panel will correlate to the others. 

Names: This is where the Names of the talking character will be held
Dialogue: This is where the actual Dialogues will be held
Character Image: You can include a 2D Image of who is talking to add more context though it can be left blank
Side: This will hold a value that decides which side the name and image will be on. Please input 1 (Left) or 2 (Right)
